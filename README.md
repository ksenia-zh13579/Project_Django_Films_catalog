# Каталог анимационных фильмов и сериалов

## Назначение

Интерактивный каталог анимационных фильмов и сериалов. Пользователь может
ознакомиться с произведением, присвоить ему статус («хочу посмотреть»,
«смотрю», «просмотрено» или «брошено»), поставить оценку от 1 до 10 и
посмотреть среднюю оценку.

## Предметная область

Предметная область — категоризация анимационных произведений.

## Основные классы

### `Film`

Описывает фильм или сериал. Основные атрибуты: `name`, `director`, `genres` и
коллекция `ratings`. Метод `add_rating` добавляет оценку, а
`average_rating` вычисляет среднее значение.

### `User`

Описывает пользователя каталога. Атрибуты — `name` и словарь `statuses` со
статусами произведений. Методы `set_status` и `rate_film` изменяют состояние
каталога и связывают пользователя с произведением.

### `Rating`

Описывает оценку пользователя произведению. Атрибуты `user`, `film` и `value`.
Конструктор проверяет диапазон от 1 до 10.

Все классы реализуют `__init__` и понятное строковое представление через
`__str__`. Коллекции произведений и пользователей представлены обычными
списками, а функции `find_film`, `save_films`, `load_films`, `save_users` и
`load_users` выполняют операции над коллекциями и JSON.

## Взаимодействие объектов

Пользователь вызывает `set_status(film, status)` для изменения своего статуса
и `rate_film(film, value)` для создания объекта `Rating`. Оценка добавляется
в коллекцию выбранного `Film`, после чего `average_rating()` вычисляет общий
результат. При загрузке JSON оценки снова связываются с объектами пользователей
и произведений.

## Данные

Начальные данные находятся в [`data/films.json`](data/films.json) и
[`data/users.json`](data/users.json). Запуск `main.py` создаёт или обновляет
эти файлы с помощью `create_initial_data()`.

## Структура проекта

```text
.
├── main.py                 # доменные классы, коллекции и JSON-хранилище
├── models/
│   ├── film.py             # класс Film
│   ├── rating.py           # класс Rating
│   └── user.py             # класс User
├── data/
│   ├── films.json          # произведения и оценки
│   └── users.json          # пользователи и статусы
├── tests/
│   ├── test_film.py        # тесты класса Film и операций с фильмами
│   ├── test_rating.py      # тесты класса Rating
│   └── test_user.py        # тесты класса User
└── films_catalog/          # заготовка Django-проекта
```

## Тесты и проверка качества

Установите зависимости разработки из [`requirements.txt`](requirements.txt),
затем выполните:

```bash
python -m pip install -r requirements.txt
pytest
flake8 main.py tests
```

Тесты проверяют взаимодействие объектов, среднюю оценку, сериализацию,
загрузку JSON и обработку некорректных статусов и оценок.

## Запуск программы

```bash
python main.py
```

Для запуска Django-заготовки:

```bash
python films_catalog/manage.py runserver
```
