# Каталог анимационных фильмов и сериалов

## Назначение

Интерактивный каталог анимационных фильмов и сериалов, позволяющий ознакомиться с полной информацией о нужном произведении, присвоить ему один из статусов (хочц посмотреть/просмотрено/смотрю/брошено), поставить ему оценку и посмотреть его общую среднюю оценку.

## Целевая аудитория

Пользователи всех возрастов, увлекающиеся анимацией и испытавающие потребность в систематизации интересующих их анимационных произведений.

## Предметная область

Предметной областью является категоризация художественных произведений.

## Основные сущности

- пользователь
- произведение
- оценка

## Основные функции

- Вывод всех доступных произведений
- Добавление нового произведения в список
- Добавление нового статуса к произведению
- Выставление оценки произведению
- Просмотр общей средней оценки произведения

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
